# LINE Taiwan Service Audit

## Overview

Use this skill to generate a repeatable quality audit for Taiwan teaching service. It turns three operational data sources into an Excel workbook and a management summary:

- LINE OA chat CSV zip export.
- Student-teacher matching workbook.
- Optional SmartBI `海外教学SOP质检明细` CSV.

The workflow preserves original student, teacher, user ID, and file identifiers for traceability. It uses `合格 / 问题 / 待复核 / 不适用` rather than percentage scoring unless the user explicitly asks for another scoring model.

## Inputs

Required for the base audit:

- `--line-zip`: ZIP containing LINE OA chat CSV files.
- `--student-xlsx`: workbook containing at least `学员ID`, `学员姓名`, `老师ID`, `老师名称`.
- `--output-dir`: output directory.

Optional second-stage BI integration:

- `--bi-csv`: SmartBI CSV named like `海外教学SOP质检明细`, usually GB18030 encoded.
- `--audit-xlsx`: workbook generated by `line_quality_audit.py`.

Useful student workbook fields, when present:

- `阶段`, `课类`, `班级语种`, `下节课上课时间`, `学员是否新签`, `学员当前使用的课包剩余课时数`, `学员换到当前教师的日期`.

Expected BI fields:

- `上课日期`, `上课时间`, `课节id`, `主讲id`, `主讲昵称`, `用户id`, `用户昵称`.
- SOP status fields such as `是否首课`, `首课自我介绍`, `首视邀约`, `首视`, `课程预告`, `课后_文字总结`, `课后_截图`, `课后_语音反馈`, `课后_三部曲`, `是否0课时任务学员`, `0课时结课回访`, `是否4课时任务学员`, `4课时语音回访`, `4课时文字回访`.

## Workflow

1. Run the base LINE audit:

```bash
python scripts/line_quality_audit.py \
  --line-zip "/path/to/line_oa_chat_csv.zip" \
  --student-xlsx "/path/to/台教团队学员明细.xlsx" \
  --output-dir "/path/to/outputs" \
  --prefix "台湾教师团队教学服务质检"
```

2. If the user provides the BI SOP detail CSV, run BI integration:

```bash
python scripts/integrate_bi_audit.py \
  --audit-xlsx "/path/to/outputs/台湾教师团队教学服务质检结果.xlsx" \
  --bi-csv "/path/to/海外教学SOP质检明细.csv" \
  --output-dir "/path/to/outputs" \
  --prefix "台湾教师团队教学服务质检"
```

3. Inspect the resulting workbook before finalizing:

- Base workbook sheets include `总览`, `教师汇总`, `学员会话明细`, `问题证据`, `规则命中`, `规则命中明细`, `待复核`, `未匹配清单`, `维度分析`.
- BI workbook sheets include `总览_BI整合`, `规则变化`, `教师汇总_BI整合`, `会话明细_BI整合`, `BI判定变更`, `问题清单_BI整合`, `待复核_BI整合`, `BI课次汇总`.

4. In the final response, report:

- Output workbook and summary report links.
- LINE conversations read, message count, matched/unmatched conversations.
- Original and BI-integrated `待复核` counts when BI is used.
- Top issue categories and key caveats.

## Audit Logic

Base LINE audit:

- Match conversations to students first by `学员ID` in filename or message text, then by `学员姓名`, then by weak teacher/stage hints only when unique.
- Treat `Account` sender rows as teacher-side messages and `User` rows as parent/student-side context.
- Detect SOP evidence using simplified/traditional Chinese keywords and common LINE export phrases.
- Put uncertain evidence into `待复核`, especially media-only traces such as `影片已傳送`, `照片已傳送`, `檔案已傳送`, or cases needing exact course/lesson state.

BI integration:

- Match BI rows to audited conversations by `用户id` / `学员ID`; if teacher IDs match, narrow to that teacher.
- Use BI `完成/未完成` statuses to reduce `待复核` only when the BI field directly applies.
- Mark renewal follow-up as `不适用` when `是否4课时任务学员=否`.
- Mark conclusion/0-hour follow-up as `不适用` when `是否0课时任务学员=否`.
- Do not override clear LINE `合格` evidence with BI `未完成`.
- Leave first-video, teacher-change, and operation-guide items as `待复核` when BI fields are empty or unavailable.

## Caveats

- The scripts do not inspect video, audio, image, or file contents; they only read LINE CSV text markers and BI status fields.
- Exact timing checks depend on structured course data. Without BI or course-record exports, many timing-based rules should remain `待复核`.
- SmartBI access and export are outside this skill. If BI domain access is blocked, ask the user to export the CSV manually and provide it.
- The generated conclusions are operational audit aids, not final disciplinary determinations. Keep evidence columns available for manager review.
