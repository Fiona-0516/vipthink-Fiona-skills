# 钉钉机器人配置指南

## 1. 创建钉钉应用

1. 登录 [钉钉开放平台](https://open-dev.dingtalk.com/)
2. 创建企业内部应用
3. 获取 AppKey（CLIENT_ID）和 AppSecret（CLIENT_SECRET）

## 2. 配置机器人

1. 应用能力 → 添加「机器人」能力
2. 消息接收模式选择 **Stream模式**（不需要公网回调地址）
3. 机器人名称设为 `教务小助手`

## 3. 权限配置

应用需申请以下权限：
- 企业内机器人发送消息
- 机器人读取用户发给机器人的消息
- 获取用户基本信息

## 4. 可见范围

"应用发布"→"版本管理与发布"→"可用范围"：
- 默认仅管理员可见，需改为**全员可见**

## 5. 群内添加机器人

1. 钉钉群 → 设置 → 智能群助手 → 添加机器人
2. 选择「教务小助手」
3. 群内@教务小助手 即可触发

## 6. 关键词配置

钉钉webhook机器人需要配置**关键词**才能发送成功：
- 常用关键词：`工单`、`DEMO`、`通知`、`CRM`、`查班`、`锁班`
- 在群机器人设置中添加

## 7. 代码中的配置位置

`bot.py` 顶部：
```python
CLIENT_ID = os.getenv("DINGTALK_CLIENT_ID", "")
CLIENT_SECRET = os.getenv("DINGTALK_CLIENT_SECRET", "")
```

## 8. 启动

```bash
./start.sh start    # 启动
./start.sh stop     # 停止
./start.sh status   # 状态
./start.sh logs     # 查看日志
```
