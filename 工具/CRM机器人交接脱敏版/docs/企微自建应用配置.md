# 企微自建应用配置指南

## 1. 创建自建应用

1. 登录 [企业微信管理后台](https://work.weixin.qq.com/)
2. 应用管理 → 自建 → 创建应用
3. 记录 AgentId 和 Secret

## 2. 配置接收消息（回调URL）

⚠️ **前提**：需要备案域名（公司主体一致的域名，如 `wecom.vipthink.cn`）

1. 进入应用 → 接收消息 → 设置API接收
2. 填写：
   - **URL**: `https://wecom.vipthink.cn/wecom/callback`
   - **Token**: `<WECOM_CALLBACK_TOKEN>`
   - **EncodingAESKey**: `<WECOM_ENCODING_AES_KEY>`
3. 点保存时企微会发GET请求验证，服务必须已启动

## 3. 配置可信域名

1. 应用 → 网页授权及JS-SDK → 设置可信域名
2. 填写: `wecom.vipthink.cn`
3. 需要域名验证文件

## 4. 配置IP白名单

1. 企业微信管理后台 → 安全与合规 → IP白名单
2. 添加服务器公网IP

## 5. 可见范围

1. 应用 → 可见范围
2. 设置为全员或指定部门

## 6. 企微智能体配置（可选）

如果要用企微智能体+插件方式：

1. 企微管理后台 → 智能工作台 → 创建智能体
2. 添加工具 → 自定义插件
3. 配置：
   - 请求URL: `https://wecom.vipthink.cn/api/command`
   - 请求方式: POST
   - 参数全走Body，类型为String
   - Header: `X-API-Key: <CRM_API_KEY>`

## 7. DNS配置（需IT部门）

```
类型：A记录
主机记录：wecom
记录值：服务器公网IP
```

子域名继承主域名ICP备案，不需要重新备案。

## 8. SSL证书

使用Let's Encrypt免费证书：
```bash
apt install certbot python3-certbot-nginx
certbot --nginx -d wecom.vipthink.cn
```

## 9. Nginx配置参考

```nginx
server {
    listen 443 ssl;
    server_name wecom.vipthink.cn;

    ssl_certificate /etc/letsencrypt/live/wecom.vipthink.cn/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/wecom.vipthink.cn/privkey.pem;

    location /wecom/ {
        proxy_pass http://127.0.0.1:8091;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_read_timeout 120s;
    }

    location /api/ {
        proxy_pass http://127.0.0.1:8090;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```
