# CRM 机器人交接脱敏版

这个目录来自桌面文件 `crm_bot_handover.tar.gz`，上传前已做脱敏处理。

## 已处理内容

- 保留代码、文档、配置结构和启动脚本。
- 将企微、钉钉、CRM API 的真实密钥改为环境变量读取。
- 将 `config/api_key.txt` 改为说明文字，不保留真实密钥。

## 不要提交的内容

- 真实 API key
- 企微 secret
- 钉钉 appSecret
- 钉钉 webhook access_token
- CRM 登录 token
- 真实客户、家长、学生或老师隐私数据

CRM_API_KEY
