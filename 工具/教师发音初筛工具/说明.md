# 教师发音初筛工具

这是一个可直接运行的网页工具，用于初筛多语种教师候选人的发音和教学表达能力。

- 候选人选择粤语、台湾腔普通话、英语中的一种或多种测试
- 每个语种随机抽题，重录不换题
- 每个语种最多录制 3 次，每次视频都存档
- 粤语使用香港繁体字，台湾腔普通话使用台湾繁体字
- 英语使用中文教学场景提示，要求候选人用英语表达
- 后台按语种独立展示最终结论和历史录制
- 题库按语种管理，每种语言默认至少 10 条话术

## 怎么打开

最简单的方式：直接打开本目录里的 `index.html`。

如果浏览器因为权限限制不能录制视频，可以在本目录启动本地网页服务：

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

然后访问：

```text
http://127.0.0.1:4173
```

## 说明

当前版本的评分是本地模拟评分，正式上线时可以升级为：

- 发音评估：判断发音、流利度、完整度、韵律
- 语音转文字：检查候选人说的内容是否准确
- AI 评分：判断教学表达是否自然、清楚、适合海外孩子和家长

视频文件保存在浏览器 IndexedDB，候选人、题库和报告元数据保存在 localStorage。
