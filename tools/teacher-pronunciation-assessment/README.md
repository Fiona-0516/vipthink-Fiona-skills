# 多语种教师候选人发音初筛工具

这是一个可直接运行的前端 MVP，用于演示：

- 候选人选择粤语、台湾腔普通话、英语中的一种或多种测试
- 每个语种随机抽题，重录不换题
- 每个语种最多录制 3 次，每次视频都存档
- 粤语使用香港繁体字，台湾腔普通话使用台湾繁体字
- 英语使用中文教学场景提示，要求候选人用英语表达
- 后台按语种独立展示最终结论和历史录制
- 题库按语种管理，每种语言默认至少 10 条话术

## 运行

在本目录启动一个静态服务：

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

然后访问：

```text
http://127.0.0.1:4173
```

## 说明

当前版本的评分是本地模拟适配器，代码集中在 `simulateAssessment`。正式上线时可以把这个函数替换为：

- Azure Speech Pronunciation Assessment：发音、流利度、完整度、韵律
- OpenAI Speech-to-Text / LLM：转写、内容匹配、英语教学场景适配度、异常解释

视频文件保存在浏览器 IndexedDB，候选人、题库和报告元数据保存在 localStorage。
