# 团队 AI 学习观察技能

## 用途

帮助教学负责人观察团队成员是否持续学习 AI、是否有 GitHub 产出、是否需要提醒或支持。

## 适合谁用

- 教学负责人
- 项目负责人
- 需要做团队周报的人

## 怎么用

每周固定检查团队成员的 GitHub 仓库和项目产出，记录：

- 活跃成员数量
- 正常有产出的人
- 空仓库或 404 仓库
- 近 30 天提交数量
- 新增产出物
- 更新产出物
- 需要提醒的问题

## 可观察问题

- 仓库为空。
- 仓库 404 或 token 不可读。
- 仓库名和飞书登记不一致。
- 多天没有提交。
- 有提交但没有实际产出物。
- 产出和岗位目标不匹配。

## 输出建议

每周输出一份中文简报：

```markdown
# 团队 AI 学习观察周报

## 本周概况

## 正常产出

## 需要提醒

## 下周建议
```

## 来源

参考刘亚的团队 GitHub 管理要求和 AI 观察方式，整理为教学负责人可用的中文版本。
