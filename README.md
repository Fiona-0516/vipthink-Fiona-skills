# vipthink-Fiona-skills

这是一个用于整理和沉淀个人 AI 使用方法、技能说明、工作流模板和学习记录的仓库。

## 仓库内容

- `skills/`：可复用的技能说明或提示词模板
- `docs/`：项目说明、流程文档和治理规范
- `examples/`：脱敏示例或 fake data
- `scripts/`：辅助脚本
- `config.example.*`：示例配置文件

## 数据与安全边界

本仓库不用于存放真实业务数据、客户资料、学生/家长信息、账号密码、Token、Cookie、密钥、合同、报价、订单、营收、成本、内部策略或系统导出文件。

如需示例数据，只能使用 fake data、脱敏数据或公开来源数据，并放在 `examples/` 目录中。

## 使用规范

1. 修改前先同步最新版本。
2. 新任务使用独立分支。
3. 提交前检查 changed files。
4. 不上传 `.env`、密钥、导出表格、截图、日志或临时文件。
5. 通过 Pull Request 合并到 `main`。

## 发布检查

仓库公开、分享或交付前，请完成 `PUBLISH_CHECKLIST.md` 中的检查项。
