# Fiona 的中文教学 AI 技能库

面向海外中文教学团队的 AI 技能库、教师培训 SOP 与质检工具集合。这里沉淀可直接复用的教学技能、运营流程、数据工具和团队 AI 学习资料，重点服务教师培训、课后服务、质量评估和团队知识管理。

线上入口：[Fiona 中文教学技能库](https://fiona-0516.github.io/vipthink-Fiona-skills/)

## 项目亮点

- 中文优先：目录、说明和协作规则尽量使用中文，方便非技术同事直接阅读。
- 场景真实：内容来自教学运营、教师培训、质量检查、AI 分享等一线工作场景。
- 可复用：每个技能尽量写清用途、适用对象、使用方法和参考来源。
- 有工具：包含教师发音初筛、AI 学习分享、CRM 脱敏示例、SmartBI 数据工具等页面或脚本。
- 重视安全：不提交 token、账号、学生家长隐私、业务原始数据和私密截图。

## 怎么新增自己的技能

1. 先确认这个技能属于教学、运营、数据还是工具。
2. 在对应中文目录下新建一个中文文件夹或 Markdown 文件。
3. 每个技能至少写清楚四件事：用途、适合谁用、怎么用、来源或参考。
4. 不放 token、账号、学生家长隐私、业务原始数据和私密截图。
5. 提交前自查：说明能看懂、链接能打开、没有敏感信息。

## 协作流程

团队整理技能时建议先开独立分支，完成后再发 Pull Request 给团队检查。

```bash
git switch -c feature/chinese-teaching-skill-library
git add .
git commit -m "整理中文教学技能库"
git push origin feature/chinese-teaching-skill-library
```

然后在 GitHub 页面创建 Pull Request，合并前确认测试和内容检查都通过。
